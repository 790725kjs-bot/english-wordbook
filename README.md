# 내 영어 단어장 (English Vocab Trainer)

갤럭시 탭 **분할 화면** 학습용 영어 단어 앱입니다.
왼쪽에 유튜브 영어 팟캐스트, 오른쪽에 이 앱을 띄워 두고 —
번역기에서 복사한 단어를 **붙여넣기 한 번**으로 사전 뜻·예문까지 저장하고 반복 암기합니다.

설치 없이 브라우저에서 돌아가는 웹앱(PWA)이라, 홈 화면에 추가하면 일반 앱처럼 열립니다.

> 📖 화면별 조작법은 **[사용설명서.md](사용설명서.md)** 를 보세요.

## 🔗 접속 주소

**https://790725kjs-bot.github.io/english-wordbook/**

PC를 켜 두지 않아도 되고, 홈 화면에 추가하면 지하철에서도 오프라인으로 동작합니다.

## 1. 핵심 사용 흐름

| 단계 | 조작 |
|---|---|
| ① | 유튜브 자막의 모르는 단어를 S펜 번역기로 확인 → **복사** |
| ② | 오른쪽 앱의 입력창에 **붙여넣기** (붙여넣는 순간 자동으로 검색됩니다) |
| ③ | 영어 단어와 한글 뜻이 자동으로 분리되고, 사전 뜻·예문·발음이 표시됩니다 |
| ④ | **★** 를 누르면 단어장에 저장 (추가한 순서대로 쌓입니다) |
| ⑤ | 이동 중이나 복습 시간에 **암기** 탭에서 반복 학습 |

> `resilient 형용사 회복력 있는` 처럼 품사·발음기호가 섞여 있어도
> 영어 단어와 한글 뜻만 알아서 골라냅니다.

---

## 2. 기능

### 찾기
- 붙여넣기 즉시 자동 검색, 클립보드 버튼 1탭 입력
- 영어 뜻 + **예문** + 발음(원어민 음원 또는 TTS) + 동의어
- 예문마다 **한글 뜻**을 함께 저장 (사전에 예문이 없으면 Wiktionary 용례로 보충)
- 사전에 없으면 원형을 추정해 재검색 (`running` → `run`)
- 뜻을 직접 수정 가능 (탭해서 입력)
- **여러 단어 한 번에 추가** — 갤럭시 노트에 적어 둔 목록을 통째로 붙여넣어 이관

### 단어장
- **즐겨찾기 추가 순서** 그대로 보기 (알파벳순 아님) — 순서 번호 표시
- 정렬 전환: 추가순 / 최근순 / 알파벳순 / **덜 외운 순**
- **폴더 분류** (팟캐스트별·주제별)
- **뜻 가리기** 토글로 셀프 체크
- **보관함** — 별표를 꺼도 뜻·예문·암기 기록이 남아, 시간이 지난 뒤 다시 확인 가능
- 단어를 누르면 세부 뜻·예문·메모·암기 기록 상세 보기

### 암기 (4가지 모드)
| 모드 | 방식 |
|---|---|
| 🃏 **플래시카드** | 단어 → 2초 안에 떠올리기 → 자가 채점 (요청하신 핵심 규칙) |
| ✅ **객관식** | 4개 보기 중 뜻 고르기, 자동 채점 |
| ⌨️ **스펠링** | 한글 뜻을 보고 영어 철자 입력 |
| 🎧 **연속 듣기** | 단어→예문을 자동 재생하며 핸즈프리 복습 |

**반복 규칙 (요청하신 내용)**
- 단어가 뜬 뒤 **2초 이내**에 답하고 정답이면 *즉답 성공*
- 즉답이 **4회 연속** 쌓이면 → 그 단어는 대기열 **맨 뒤로** 밀리고 새 단어가 올라옴
- 느리게 답하거나 틀리면 → 연속 기록 초기화 + 앞쪽으로 복귀
- 새로 저장한 단어는 대기열 **앞쪽**에 배치되어 먼저 나옵니다
- 2초·4회 기준은 설정에서 조절 가능

### 그 외
- 오프라인에서도 저장된 단어·예문으로 학습 가능
- JSON / CSV 백업, 가져오기
- 기본 단어팩 65개 (영어 팟캐스트 빈출 표현) 내장
- 다크 모드 자동 대응

## 3. 갤럭시 탭에 올리는 방법

### 방법 A. PC에서 서버로 띄워 태블릿에서 접속 (가장 간단, 추천)

PC와 태블릿이 **같은 와이파이**에 있어야 합니다.

```powershell
cd "C:\Users\김하람\Documents\00. AI 활용\06. 영어 공부 (단어 공부 어플 제작)"
python -m http.server 8000
```

그 다음 PC의 IP를 확인하고 (`ipconfig` → IPv4 주소, 예: `192.168.0.5`)
태블릿 크롬에서 `http://192.168.0.5:8000` 으로 접속합니다.

### 방법 B. 무료 호스팅에 올려 상시 사용 (PWA 설치·오프라인 지원)

1. [github.com](https://github.com) 에 저장소를 만들고 이 폴더의 파일을 업로드
2. Settings → Pages → Branch를 `main` / `root` 로 지정
3. 발급된 `https://아이디.github.io/저장소이름/` 주소를 태블릿에서 열기
4. 크롬 메뉴 → **홈 화면에 추가** → 앱처럼 실행 + 오프라인 사용 가능

> 넷리파이(netlify.com)에 폴더를 끌어다 놓는 방법도 동일하게 동작합니다.

### 방법 C. 파일만 복사해서 열기

USB나 클라우드로 폴더째 태블릿에 옮긴 뒤 `index.html` 을 브라우저로 엽니다.
단어 저장·암기는 정상 동작하지만, **홈 화면 앱 설치와 오프라인 캐시는 되지 않습니다**
(브라우저 보안 정책상 `file://` 에서는 서비스워커가 동작하지 않습니다).

### 분할 화면 사용법
최근 앱 버튼 → 유튜브 아이콘 길게 누르기 → **분할 화면으로 열기** →
반대쪽에 브라우저(또는 설치한 단어장 앱) 선택. 경계선을 드래그해 비율을 조절하세요.

## 4. 데이터 보관 주의

모든 단어는 **그 브라우저 안에만** 저장됩니다(localStorage).
브라우저 데이터/저장공간을 지우면 단어장도 사라지므로,
가끔 **설정 → 내보내기(JSON)** 로 파일을 남겨 두세요. 기기를 바꿔도 가져오기로 복원됩니다.

## 5. 파일 구조

```
index.html              화면 구조
css/styles.css          스타일 (다크 모드·태블릿 반화면 대응)
js/store.js             저장소: 단어·폴더·순서·설정·백업
js/api.js               사전 조회, 번역, 발음, 붙여넣기 파서
js/review.js            암기 엔진 (2초 즉답 / 4회 연속 / 대기열)
js/app.js               화면 로직 (찾기·단어장·암기·설정)
js/pack.js              기본 단어팩
sw.js                   오프라인 캐시
manifest.webmanifest    앱 설치 정보
tests/                  검증 스크립트
```

사용 API (무료·키 불필요)
- 사전·예문: [Free Dictionary API](https://dictionaryapi.dev) → 장애 시 [Wiktionary](https://en.wiktionary.org) → [Datamuse](https://api.datamuse.com) 순으로 자동 전환
- 철자 교정 제안: Datamuse
- 한글 번역: [MyMemory](https://mymemory.translated.net)
